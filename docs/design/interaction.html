01

交互契约

所有核心操作共享的五条规则。

显式

保存、移动、删除、恢复、迁移都有明确动作。

可解释

反馈说明相对路径、索引或每日设备状态中哪一层改变。

保留输入

错误不清空表单，不覆盖磁盘旧版本。

可退出

危险动作可取消；取消不产生副作用。

有限

keikeu 到外部编辑器为止，不继续追踪正文。

每日启动：每台设备按本地日期首次启动显示一次内置鼓励卡；3 秒、Enter 或“开始写”进入空白 Paper。设备状态只记录当天日期。
写入边界：Vault、config 与 state 的持久写入必须 resolve 到当前用户 Home 内；symlink 逃逸或 Home 外旧 Vault 立即停止写入。

Flashcard：有限上下文

Summary 永远是第 1 张；每条 Highlight 增加一张。

FLASHCARD · 1 / 3

合成 Summary：这里只展示整体火种。

页

合成 Summary：这里只展示整体火种。

只读边界

  • Library / index 传入 Vault-relative path，不通过 code 猜文件。
  • 每次打开、切换 Paper 或重启都从第 1 页开始；位置不持久化。
  • 卡片列表可点击；左右键与上一张 / 下一张不循环，越界给短提示。
  • 页码只接受 1..N 整数；非法输入不移动。
  • Highlight 卡可临时展开当前 Summary，但不预览相邻卡。
  • 顶部 Paper selector 显示“名称 (code)”或 code；“返回 Paper”保留路径上下文。
没有：编辑、完成、跳过、消费、正文输入、进度百分比。
04

Library：一层组织、检索与恢复

它是资产入口，不是项目管理器；header 始终显示当前 Vault path 与“更换 Vault…”。

folder scope + search全部 / 未归类 / 一层文件夹；名称 / code / Summary / Tags / Highlight 名称
list_papers()读取含 path / folder 的本地 v3 index
dense result row编辑 / Flashcard / 移动 / 分支 / 系统打开
explicit path operations单个拖放或菜单；勾选批量逐项报告
.trash/cache/{root,folder}/恢复时检查不可变 code 冲突

Empty

区分空 Vault、空文件夹、空 Trash 与搜索无结果；保留 scope 并给出最短下一步。

Damaged file

错误列表显示相对路径与解析原因；健康 Paper 仍可检索。

Selection

全选仅限当前 scope；切换 scope 清空选择并显示短行内说明。

Partial result

move / merge / restore / delete 逐项显示成功与失败；失败项留在原处。

Restore conflict

active code 冲突时阻止该项并留在 Trash；不改历史 code，永不覆盖活动文件。

每个 Paper / folder 拖放都有可键盘到达的“移动到…”菜单等价入口；进入 Library 或显式 Refresh 重建 index，不运行文件监听器。
Vault switch：有效 Vault 先预览 Paper 数；空目录需确认初始化；非空非 Vault 拒绝。验证与确认成功后才原子替换 config。
Trash：固定入口始终显示数量；恢复不覆盖。永久删除 1–3 个 Paper 需确认，4 个以上需 trim-exact 小写 `execute`，并逐个处理明确 path。
05

Home 安全搬迁与 v0.1 迁移

白名单外 Vault 先只读分类，再无跟随复制验证；只有 Home 内安全副本可切换或迁移。

源 Vault 只读分类

停止写入，不跟随/解引 symlink；任何 symlink 或 special entry 都报错，来源与 config 不变。

NO WRITE
选择 Home 内目标并确认

取消即停止；未确认时不复制、不改 config。

GATE
复制普通目录与 regular files

在全新 Home 目标中比对 regular-file manifest 与逐文件 bytes；原 Vault 保留。

RELOCATE
v2/v3 验证并切换

逐 Paper 解析，重建并验证 index；全部通过后才原子更新 config。

V2/V3 SWITCH
v0.1 副本预检并切换

不先当作 v2/v3 Paper 解析；现有只读 preflight/manifest 通过后原子选择该安全副本。

V0.1 SWITCH
v0.1 显式迁移 gate 与备份

切换后才可确认迁移；备份位于活动 Vault 外、但仍在 Home 内。

MIGRATE GATE
隔离 staging 转换与逐个验证

取消或任何 Cache 失败都不切换 migration staging，未改写的安全 v0.1 副本仍被选中。

STAGE
原子切换与报告

全部 Paper 验证后才移除活动旧 Outline。

COMMIT
P0 停止规则：疑似数据丢失、静默改写或半迁移时立即停止写入和重复实验；保护原 Vault，只记录脱敏步骤。
06

错误与恢复

错误消息必须说明未发生什么，以及下一条安全路径。

情况立即行为资产保证下一步
Summary 为空字段旁阻止保存旧文件不变补 Summary 或离开
Paper 被外部删除/移动拒绝保存不重建假文件回 Library 刷新
Paper 被外部修改拒绝覆盖外部字节不变重新打开并人工决定
代号冲突拒绝新建 / move / restore两边都不覆盖、不自动改 code作者处理重复项或取消
单 Paper 损坏索引记录 error其他 Paper 继续外部文本工具检查
本地 daily state 损坏视为今天尚未显示启动卡Paper / Vault 不变继续使用
Home 外路径 / symlink / special entry只读分类；不跟随且立即停止写入任何不支持项中止搬迁，原 Vault / config 不变仅普通目录/regular files 可复制验证到 Home
深层目录 / symlink asset索引记录 error，阻止相关操作不写穿、不递归删除作者在 Finder 修复
Provider 冲突副本按未知文件处理不自动合并文字作者在系统层处理
