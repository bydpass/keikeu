调用与反馈

用户动作Vue 保留表单输入，发送语义 method 与 DTO；不发送绝对路径或 source bytes。
本地边界Rust 为请求编号并串行写入 JSONL；Python application service 调用现有 Core。
成功Vue 只应用匹配 request id 的结果，并重新显示 Python 排序后的状态。
已知失败错误必须标出 UI、host、transport、sidecar、service、Core 或 disk/provider 层。
提交状态未知mutation 不自动重试；显示 commit_unknown，重新加载磁盘事实后再决定。
sidecar 重启重新执行 system.hello；旧 edit/preview/preflight token 全部失效。

  • sidecar unavailable、protocol mismatch、recovery。
  • 危险动作的说明、确认、取消与逐项结果。
