核心交互约束

Paper Desk只编辑名称、Summary、Highlights、Tags；原始草稿锁定并说明只读。任一受控字段偏离最近成功保存值时显示「未保存」。
保存基线保存按钮与 Cmd+S 调用同一函数。只有成功写入 Markdown 才更新 baseline；失败、stale 或 commit_unknown 均保留表单和原 baseline。
离开保护dirty 时，导航、切换或新建 Paper、切换 Vault、关闭窗口都进入同一原生二选一：放弃更改并回到最近基线，或继续编辑并取消动作。不提供「保存并前往」。
Flashcard只读取最近成功保存的名称、Summary 与 Highlights；第 1 张为 Summary，之后每张只显示 1 个 Highlight，Summary context 由用户手动展开；每次打开回到第 1 张。
Libraryscope、search query、sort order、active item、batch selection 与 scroll position 仅在当前进程内往返保留；成功切换 Vault 或应用重启后重置。
侧栏与滚动桌面布局中，Paper、Flashcard 与 Library 的上下文栏固定在全局栏右侧。Paper 与 Library 继续滚动主文档；Flashcard 只滚动卡片列表，标题与 Paper selector 不动。根与嵌套滚动容器均禁止 overscroll bounce 和 scroll chaining；滚动条外观隐藏，但鼠标、触控板与键盘滚动保留。
Vault / migration保留既有选择、初始化、切换、复制验证、迁移确认与恢复边界；视觉改造不改变路径、Markdown、Core 或持久化语义。
Core recoveryblocked、protocol mismatch、sidecar unavailable、session expired 与 commit_unknown 使用同一纸面层级，但必须保留明确的故障层、恢复动作和安全 gate。

全部页面的状态

  • default、empty、loading/busy、disabled。
  • field validation、stale snapshot、conflict。
  • sidecar unavailable、protocol mismatch、recovery。
  • 危险动作的说明、确认、取消与逐项结果；视觉层级不能弱化安全边界。

键盘、窗口与动效

  • 所有可操作元素有可见 :focus-visible，Tab 顺序与视觉顺序一致。
  • Paper 字段失焦后仍可辨识；Highlight 拖动保留上移、下移按钮等价路径。
  • 1220×780 与 920×680 不横向溢出、不裁文字，动作保持可达。
  • 鼠标、触控板或键盘滚动到顶/底时不回弹；滚动条外观不显示；长 Flashcard 列表的滚动不带动外层页面。
  • prefers-reduced-motion 关闭非必要动效；任何流程都不依赖动画理解或完成。
