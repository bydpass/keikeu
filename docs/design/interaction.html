Road v0.7 complete · accepted CP8 presentation

位置Paper 与 Library 是同级日常位置；Vault 是环境入口。已接受顶栏保持单行 56px，顺序为“编辑 Paper → 新 Paper → Library … Vault”。
离开保护从 dirty Paper 去 Library、新 Paper 或 Vault 均复用 PaperView.confirmDeparture()；取消时 destination 不变。
新 Paper只在 guard 通过后清空 path 并替换 PaperView；确认只执行一次原 intent。
Vault / 阻塞Vault 往返保留已保存 Paper path；blocking recovery 不被 Shell 隐藏。
CP7 Tags一个单行 comma-separated 字段使用可逆 CSV-style 引号；底层仍传递原有有序 Tags 数组。macOS 字段关闭自动更正与智能引号转换；原生实证确认 ASCII 直引号未被改成弯引号。
CP7 详情 / dirtyPaper 详情与 Library Paper 预览均为轻量原生 Popover，不参加页面高度计算；不显示常驻 dirty 文案，但离开、新 Paper、Vault 与关闭 guard 不变。
CP8 页签滚轮全部页按钮留在 DOM 的单行局部滚轮中；约三槽、细滚动条、scroll-snap，无箭头/循环/换行。载入、选择、加页、删页后活动页自动居中。
CP8 竖版 Anchororientation: portrait 下，Paper 正文在 clamp(220px, 34dvh, 300px) 内滚动，三动作固定在底部；Library 在 Shell 下方固定“范围 / 排序”和“新文件夹”，分别打开 native Popover。

核心交互约束

命名Paper display name 与 page title 独立且始终可编辑；基础/进一步模式不改变持久字段。
类型null / summary / snapshot / whisper；一份 Paper 最多一个 Summary，已有时其他页的“总结”仍可见但禁用并解释原因。
加一页光标前留在当前页，选区起点后的内容进入新页；从未聚焦正文时在末尾分割。新页 name/type 为 null，焦点进入标题。
删除确认后删除当前页；唯一页删除时替换为一张空白页。取消或 Escape 不改变 draft。
保存按钮与 Cmd+S 调同一 whole-Paper save；已知失败保留 draft/baseline，Index 失败只显示 degraded warning。
离开保护整体 dirty；导航、Paper/Vault 切换与正常关闭统一保护。未知提交只读对账，绝不重发。
Library搜索整份 Paper；中文 composition 期间零查询，提交后一次最终词。每个结果按钮旁的 native Popover 显示第一页预览、页数、页标题和 Tags，不下压操作区；结果始终打开整份 Paper 第一页，不 deep-link。
文件夹“删除文件夹”确认后把全部内容原子移入废纸篓并可整树恢复；目标冲突时零部分合并。只有废纸篓中的“永久删除”二次确认才销毁整树，Core 不跟随符号链接或跨设备/挂载子树。
修复普通损坏文件不生成半成品；unknown-save 保留 submitted draft。Finder、复制草稿、重新检查与 Index rebuild 分开呈现。
