选好一份参考，写作时一直在上方

目标：在主应用选好整份参考（原 Paper 或整理后的 flashcard），切到任意外部 iPhone 编辑器后仍持续可见；小窗只做滚动与翻页，惯用软键盘照常输入，正文不被挡住。更换整份参考回主应用完成。

本页是设计模拟。下方手机画面由网页绘制，不是已实现的任意可交互跨应用覆盖层；小窗、键盘与编辑器的行为只有标为“真机”的条目取得过设备证据。

    市场对照（仅营销描述，未实测）

    Pip Up

    开发者宣称跨应用置顶显示文字、图片、网页并支持分页，使用 PiP。

    描述称不收集数据，商店隐私标签却列出跟踪、广告与分析数据；两者矛盾。小窗内翻页与键盘共存未核实。

    Transparent Notes 2.3.0

    更新记录：跨应用便签为“自动滚动”浮层并加入倾斜滚动；锁屏与灵动岛可分页。

    自动或倾斜滚动不等于手指滚动；本项目没有它的设备验收。

    结论与下一步

    最佳待验候选：PiP 逐屏。它是目前唯一可能同时满足“写作时持续可见、可移开不挡字、小窗内翻页”的公开接口路线，但手指滚动在结构上不满足，须由用户决定是否接受按键逐屏。它尚无任何设备证据。

    已有证据最多：Snippet。输入共存与翻页有真机证据，但滚动失败、遮挡正文，仍未达标。灵动岛展开态未验，融合入口两次失败已停止。

    下一步只做一件事：按 Ref PiP 真机 SOP 在 Ref Editor 测启动、输入共存和前进／后退换屏；Road 与 CP0 均未完成。
