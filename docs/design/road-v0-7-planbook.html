Road v0.7 · App Shell 与信息层级收口

把功能页收成一个作者工作台

Paper 和 Library 是两个日常位置；Vault 是本地环境入口；阻塞恢复是一条安全通道。Road v0.7 只把这层关系说清楚，不增加创作对象、数据合同或平台能力。

实施计划 目标设计 当前接受基线 工程与证据规则

01 · Core judgment

一个壳，两个日常位置，一个环境入口

当前缺的不是功能，而是稳定位置。视觉重构必须让作者更快找到内容，同时完整保留 v0.6 的保存、离开保护、repair 与 unknown-result 安全边界。

紧凑 App Shell → Paper / Library 日常工作面 → Vault 环境与阻塞恢复

Paper 创建、编辑、分页、保存。作者内容是视觉中心。
↔
Library 搜索、找回、整理、Trash 与系统 handoff。
→
Vault context 正常时安静；需要迁移、repair 或对账时接管工作面。
证据边界 这份 HTML 只帮助审阅目标结构。它不等于 CP1 灰阶原型，不证明 production 实现、Tauri smoke、真实作者接受或 Road 完成。

02 · Scope boundary

只收口界面，不扩产品能力

最小可交付改动集中在 Vue 的结构、层级与响应式。Python、Rust、JSONL、Markdown 和 Index 继续使用已经接受的 v0.6 合同。

包含

  • App.vue 的紧凑 Shell 与现有页面切换整合。
  • Paper、Library、Vault 的信息层级和两种目标窗口布局。
  • 现有 dirty guard、focus、错误与恢复反馈的位置校准。
  • development-only 灰阶 prototype 与 production bundle 隔离检查。
  • Vitest、Vite、Tauri smoke 与一号作者结构接受。

明确不做

  • 不改 Paper v4、Index v4、Vault 布局、protocol v2、Python 或 Rust。
  • 不加 AI ghostwriter、传统 Outline、Flashcard、配方票或正文编辑器。
  • 不加数据库、账号、同步、遥测、Router、Pinia、TypeScript 或 UI kit。
  • 不加自动保存、页重排、deep-link、恢复 journal 或 mutation replay。
  • 不进入移动端、Windows、签名、公证、DMG、tag、push 或发布。

05 · Safety contract

Shell 协调去向，PaperView 独占确认规则

不要在 App root 重写一套 dirty guard。最小接口是 PaperView 暴露 confirmDeparture()，App 只在通过后执行原来的导航 intent。

App Shell intent Paper / Library / 新 Paper / Vault。只记录目标，不先改 destination。
→
PaperView guard confirmDeparture() 复用现有 dirty、baseline 与确认文案。
→
原 intent 一次执行 取消：什么都不改。确认：只执行一次既定去向。
  • Shell 绕过离开保护：CP2 直接覆盖取消、确认、当前 path 与新 Paper remount。
  • 小窗口丢动作：每个 UI Checkpoint 都检查 920×680，不留到 CP5 才看。
  • Vault 安全信息被降级：只压低正常 context，migration / repair / commit_unknown 继续接管工作面。
  • 原型污染 production：CP1 与 CP5 两次检查 bundle，不复用本页 HTML 作为生产组件。

评审备注（仅当前预览，不写盘）：在这里记下顶栏、两种尺寸或离开保护需要调整的地方。刷新页面会清空浏览器内改动。

06 · VibeHub learning lens

边看边学：三个判断，不堆术语

VibeHub 在这里只提供知识组织和准确课程入口；页面与原型由 design-html 工作流生成。课程链接只在你主动点击时打开。

顶部导航栏

在原型里看：品牌、Paper / Library、当前位置与 Vault 环境入口是否一眼可分。

边界：保存、删除等当前页面动作不应冒充主要导航；入口越多不等于信息架构越完整。

响应式设计

在原型里看：切到 920×680 后 Library 详情纵向重排，正文和关键动作仍可到达。

边界：响应式不等于“加媒体查询”，判断标准是不同空间下阅读、点击和溢出是否仍可用。

弹窗

在原型里看：“演示未保存离开”会暂停导航，让作者选择继续编辑或放弃更改。

边界：弹窗只是呈现方式；真正的安全合同是取消不改 destination、确认后只执行一次原 intent。
