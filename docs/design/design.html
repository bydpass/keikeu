文字与可用性

  • serif 承担名称和主层级；sans 承担控件与元数据；monospace 只用于编号和路径。
  • ink blue 只标记焦点、主动作与当前上下文；危险动作保留独立颜色和说明。
  • visible focus、语义 HTML、可靠换行；prefers-reduced-motion 关闭非必要动画。
  • 1220×780 与 920×680 均不得横向溢出或裁切文字。
  • Paper、Flashcard 与 Library 的上下文栏固定；长 Flashcard 列表独立滚动，所有滚动边界无回弹；隐藏滚动条外观但保留鼠标、触控板与键盘滚动。
  • 无渐变、玻璃、硬阴影、嵌套卡片墙或装饰性药丸。
