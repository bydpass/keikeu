# 冷色折页：已批准的默认主题

2026-09-16，用户明确批准“冷色观念艺术”折页方案，并要求预设为 APP 默认主题。

## 默认实现

共享入口 `apps/desktop/src/main.js` 加载 `apps/desktop/src/style.css`，桌面与 Rust 工作面共用主题变量。默认浅色：冰灰背景、冷白纸面、雾蓝分隔、深冷灰文字；标题使用系统无衬线。保留正文的现有字体、布局、编辑行为、危险与成功状态语义色。没有新增主题切换器或持久设置。

## 图标资源与批准边界

[折页主图标概念](assets/cool-fold/app-icon-concept.png)由内置图像生成工具基于上轮折页参考生成，精确提示词保存在 [prompt.txt](assets/cool-fold/prompt.txt)。它是已批准的视觉方向，仍为扁平栅格概念，未冒充可编辑主标或 Icon Composer 分层文档。

18 个可编辑功能 SVG 位于 `assets/cool-fold/icons/`，统一 24 单位网格、1.65 单位圆头线条，继承 `currentColor`。它们是原创代码绘制图形；保留文字标签，尤其是冲突、未下载与恢复。

本次默认主题已落实到前端源码；主图标平台打包及功能图标逐控件接入尚未执行。手机／Mac 已安装的 `83c4f60` 候选不会因源码修改自动改变外观。原型里的深色预览不是已实现的原生 Dark 外观。

批准原型位于忽略目录 `tests/test-vault/icon-prototype/cool/`，含明暗、尺寸和状态演示。此前探索版本保留。此设计决定不改变 B14 待验和 CP5 尚未最终接受的状态。
