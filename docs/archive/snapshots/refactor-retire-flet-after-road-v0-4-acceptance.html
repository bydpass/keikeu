Scope · What changed / what did not

施工目标很窄：只替换桌面呈现与本地调用边界

被替换

Flet 页面、GUI entry、Flet-only builder tests，以及 UI 直接调用 Python 的旧路径。

被保留

Paper v3 Markdown、可重建索引、Vault layout、Home containment、迁移事务、外部修改拒绝和作者控制边界。

没有顺手扩产品范围。 Road v0.4 没有加入 AI 代写、正文编辑器、账号、同步、数据库、文件监听、 localhost、HTTP、WebSocket、遥测或后台网络服务。

Architecture · final runtime

最终调用链

Vue 3可见状态、表单与交互
Tauri / Rust窗口、sidecar、队列与窄系统动作
JSONL v1版本化本地消息
Application ServiceDTO、编排与 opaque handles
Python CorePaper、Vault 与文件规则
Author assetsMarkdown / Index / Vault

退役基线：Flet → Python Core → Paper Markdown / Index / Vault

Vue 的权限

只拿窄 DTO 和相对路径；不读写 Markdown，不持有绝对路径，不调用任意 shell。

Rust 的权限

管理一个 sidecar、串行请求、生命周期、目录选择和已验证的 open/reveal；不实现产品规则。

Python 的权威

Application Service 编排，Core 独占业务与文件规则；mutation 从不自动重试。

Incidents · what went wrong and how it closed

施工中真正改变路线的六件事

阶段发现处理没有扩大成什么
CP0 / CP4Rust 1.83 低于依赖图要求；beta Xcode 在 13.3 target 加载 1.88 proc-macro 失败。开发者批准并锁 Rust/Cargo 1.88；一次 11.0 override 只验证 provisional 组装。不把 provisional bundle 写成 production 或兼容证据。

CP11承载功能入口的全局栏会随窗口滚走。桌面 rail 固定在视口，内部独立滚动；窄屏保留横栏，再建 `.app` 复验。没有改行为、数据流或组件职责。
CP12IMKCFRunLoopWakeUpReliable mach port 诊断。查进程与 unified log；无崩溃、输入失效或数据异常，作为非阻塞平台观察。不为无可见症状的系统日志改产品代码。
