- `apps/desktop/` 接收现有 `frontend/`；`apps/desktop/python/` 接收原 `src/` 中两个 Python 包，导入名不变。

- Paper/JSON 字段、错误码、桥接方法和 Markdown 字节规则不变；不新增 Swift FFI、网络协议、通用后端抽象或第三方依赖。
