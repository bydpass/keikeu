先记住这一屏

在仓库根目录运行 ./dev。TUI 只管理自己启动的应用或构建任务； 它显示内存日志，也能检视 docs/manual/ 与活动文档。

  1. a：Sidecar 已存在时，直接启动完整桌面应用。
  2. b：Python 改动后，重建 Sidecar；成功才启动应用。
  3. 2 → m → /：进入文档页、选择 Manual、搜索标题或正文。
权威边界：本页是速查，不定义新行为。若与 dev、 PROJECT 或 RULES 冲突，本页错。

01

启动

从仓库根目录运行一个命令；日常操作留在同一个终端里。

./dev
  • 宿主必须是 macOS；TUI 使用系统 python3，版本至少为 3.11。
  • 终端至少为 80×24。过小时只显示当前尺寸与退出提示。
  • a 还需要 npm 与已经构建的 Sidecar；b 还需要项目 .venv。
  • 应用会读取当前本地配置；TUI 本身不直接读取、写入或修复 Vault。

02

三条常用路线

你要做什么 按键 看到什么
快速启动应用 ./dev → a 使用现有 Sidecar 运行 npm --prefix frontend run tauri:dev。
Python 改动后启动 ./dev → b 先运行 Sidecar 构建；退出码为 0 才继续启动应用。
查项目手册 2 → m → / 输入关键词，按 Enter 完成搜索，再用方向键选择。

2 打开文档页时已经默认选择 Manual；再按 m 只是显式回到该分组。

03

完整键位表

任何页面

键作用边界
1 / 2切换进程页 / 文档页。进入文档页时重新扫描当前手册。
q退出 TUI。任务运行中时先确认，发送 SIGINT 并等待整个进程组退出。
y / 其他键确认 / 取消当前危险操作。确认框出现后才生效；默认是取消。

进程页

键作用注意
a使用现有 Sidecar 启动应用。Sidecar 缺失时不会静默构建。
b重建 Sidecar，成功后启动应用。构建失败会停在日志页。
r重启应用。先确认停止，等旧 PGID 完全结束后再启动。
s确认后发送 SIGINT。可能绕过应用关闭保护并丢失未保存草稿；先保存工作。
K确认后发送 SIGKILL。强制终止会绕过应用关闭保护，只用于无法正常结束时。
PgUp / PgDn向旧日志 / 新日志滚动。日志只保存在当前 TUI 的内存 ring buffer。

文档页

键作用注意
m / dManual / Active docs。活动文档排除 archive、acceptance 与 generated。
↑ ↓ / j k移动文档选择。选择变化后预览回到顶部。
/搜索标题、路径与可见正文。开始搜索时重新扫描文档；Unicode 不区分大小写。
Enter / o用系统应用打开当前文档。打开前重新验证路径仍在仓库文档范围内。
p打开同名 PDF 附件。没有附件时只显示提示；本批新手册没有 PDF。
PgUp / PgDn滚动纯文本预览。HTML 只提取可见正文，不渲染 CSS。
Esc清除搜索。输入搜索时也可用 Esc 取消并清空。

04

状态与错误

进程页始终显示任务名、状态、PID/PGID、最近退出码与最新输出。先读状态，再决定是否重试。

提示含义下一步
找不到 npm当前 PATH 没有项目要求的 npm。按 README 完成一次性安装并核对 Node/npm。
缺少 .venvb 找不到固定的构建 Python。按 README 创建环境并安装 build requirements。
缺少 sidecar；按 b 重建并启动。a 不会猜测或自动构建。按 b 明确重建。
Sidecar 构建 已退出，code=<非 0>。应用不会继续启动。留在日志页，先修第一条实际错误。
已有任务运行中TUI 拒绝叠加第二个受管任务。等待、按 s 停止，或按 r 受控重启。
任务已切换；未发送信号确认期间旧任务已被新任务替换。重新看 PID/PGID；不要把旧确认施加到新任务。
终端至少需要 80×24当前窗口无法安全显示布局。放大终端后继续，或按 q 退出。

05

安全边界

  • 只管自己的 PGID
    TUI 只记录和操作本实例通过固定 argv 启动的进程组。
  • 不抢占 1420
    未知进程占用 Vite 端口时只会让启动失败；TUI 不替你杀它。
  • Sidecar 仍归 Rust
    TUI 不直接启动、附着或窥探应用内部 Python Sidecar。
  • 日志不落盘
    TUI 自己的合并输出只驻留内存；被包装工具可能按自己的规则生成 ignored cache。
先保存，再停止

s、q 与 K 都可能结束桌面进程。尤其 K 会绕过关闭保护；它不是日常退出键。
