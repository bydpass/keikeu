先记住三件事

keikeu 是本地桌面应用，不是 Vue 网站加 HTTP 后端。界面、桌面宿主、业务规则和作者文件 分属不同层；每层只持有完成自己责任所需的最小能力。

  1. Vue 画界面；Tauri/Rust 管桌面边界；Python 解释产品与文件规则。
  2. JSONL v2、Paper v4、Index v4 是 keikeu 的接口或格式，不是第三方库。
  3. 版本表是 2026-08-29 快照；manifest、lock、源码与现场命令才是最终事实。
当前边界：运行时仍仅有桌面 Vue/Tauri/JSONL/Python 链。Road v0.8 软件 CP0 seed 尚未批准。2026-09-04 的未来方向是共享 Rust Core 支持 iPhone 创作与 Mac iCloud 同步， 候选后独立完成桌面对等和 Python 产品运行时退役，首轮外部 Alpha 前必须收口； ADR-0009 不改变本页当前组件与命令事实。

Chapter 01

一条本地数据链

判断组件归属时，先顺着数据走：可见操作从 Vue 出发，穿过受控的原生边界，最后由 Python 读取或写入作者拥有的 Markdown。 

Vue 3 / WebView
  组件、表单、draft、可见状态
          │ @tauri-apps/api invoke
          ▼
Tauri 2 / Rust host
  五个 command、窗口、原生能力、唯一 Sidecar 生命周期
          │ stdin/stdout · JSONL v2
          ▼
Python · keikeu_bridge → keikeu_core
  DTO、业务编排、模型、路径、Markdown、Index
          │
          ├──▶ Paper v4 Markdown  作者的 durable asset
          └──▶ Index v4 JSON       可重建的辅助数据

三份项目契约，不是三项依赖

名称 它是什么 实现事实 不要误解成
JSONL v2 Rust 与 Python Sidecar 之间逐行收发 JSON 的本地协议。 bridge.rs 与 protocol.py 两端共同实现。 HTTP、WebSocket、npm 包或 Python 包。
Paper v4 作者内容的 Markdown grammar 与当前领域模型。 models.py 和 markdown_io.py。 数据库表、Vue state 或第三方 Markdown CMS。
Index v4 从 Paper 扫描结果重建的 JSON 投影。 indexer.py 输出 version: 4。 作者内容权威、数据库或必须备份的唯一副本。
层与层之间只传必要数据

Vue 不写 Markdown；Rust 不复制 Python 业务规则；keikeu_core 不导入 GUI 或 transport。 想“顺手”跨层时，先回到 Architecture 与 RULES 核对边界。

Chapter 02

Runtime：界面与业务

Runtime 是用户操作应用时真正运行的代码。本节只看可见界面与产品规则；原生宿主留到下一节。

组件 / 版本快照 用途 / 所在层 职责边界 事实来源 / 代码入口 改动后的最小检查
Vue
3.5.40		 WebView 界面运行时；组件、响应式状态、表单与可见导航。 不直接读写 Vault，不解释 Paper grammar，不持有原生进程。 frontend/package.json；main.js → App.vue。 npm --prefix frontend run test
npm --prefix frontend run build
Python stdlib
>=3.11,<3.14
现场 3.13.15		 业务与文件运行时；keikeu_bridge 编排请求，keikeu_core 处理模型和本地文件。 项目没有 Python runtime dependency；core 不导入 GUI/transport，bridge 不替 GUI 写界面。 pyproject.toml；service.py 与 src/keikeu_core/。 .venv/bin/python -m pytest

plugin-dialog 2.7.2		 原生边界的 Vue 一侧；发起 invoke 与目录选择。 只能调用 Rust 注册且 capability 允许的能力；不能绕过 host 直接操作 Sidecar。 package.json；bridge.js 与 capabilities/main.json。 npm --prefix frontend run test，再做聚焦 Tauri smoke。
Tauri / Rust
tauri 2.11.5
tauri-build 2.6.3
dialog 2.7.2 / opener 2.5.4 / shell 2.3.5
rustc 1.88.0		 桌面宿主；窗口、插件、五个 command、唯一 Sidecar worker 与退出清理。 不解析 Paper，不维护 Index，不复制 Python service 规则。 Cargo.toml；main.rs → lib.rs。 cargo test --manifest-path frontend/src-tauri/Cargo.toml，再做聚焦 Tauri smoke。
Serde / serde_json
1.0.229 / 1.0.151		 Rust 数据边界；把 command 参数和 JSONL message 变成明确的 Rust/JSON 值。 只负责表示与序列化；协议方法、重试规则和业务含义仍由 keikeu 代码定义。 Cargo.toml；commands.rs 与 bridge.rs。 cargo test --manifest-path frontend/src-tauri/Cargo.toml

Chapter 04

Build：把源码变成应用

构建链由几个小工具串起来。每个工具只产出下一层需要的东西；单层成功不能冒充完整桌面成功。

组件 / 版本快照 用途 / 所在层 职责边界 事实来源 / 代码入口 改动后的最小检查
Vite / Vue plugin
8.1.5 / 6.0.8		 前端开发与静态资源构建；把 Vue SFC 交给浏览器/WebView 可执行的资产。 不编译 Rust，不打包 Python，不证明桌面窗口或 Vault 流程。 package.json；vite.config.js。 npm --prefix frontend run build
Hatchling
build backend，当前未精确固定		 Python packaging；让 editable install / wheel 知道 src/ 下的两个包。 不是产品运行时依赖，也不负责生成 Sidecar executable。 pyproject.toml 的 [build-system] 与 wheel package mapping。 重新执行 python -m pip install -e ".[dev]"，再运行 Python tests。
PyInstaller
6.21.0		 Sidecar packaging；把 Python 入口与项目包封装成当前 target 的 onefile binary。 不构建 Vue/Rust app，不决定 protocol 或文件规则。 requirements-build.lock；build_sidecar.py → sidecar_entry.py。 .venv/bin/python scripts/build_sidecar.py
Cargo
1.88.0		 Rust package manager 与 compiler driver；解析 Cargo manifest/lock 并构建 host。 不安装 npm/Python 包；cargo test 只覆盖 Rust 层。 Cargo.toml 与 Cargo.lock。 cargo test --manifest-path frontend/src-tauri/Cargo.toml
Tauri CLI
2.11.4		 桌面构建编排；连接 Vite、Cargo、配置与 externalBin。 tauri:dev 是开发链，tauri:build 是 bundle 构建；两者都不等于签名、公证或产品接受。 package.json；tauri.conf.json。 npm --prefix frontend run tauri:dev（受控 smoke）

完整链路与产物边界见 构建与打包手册；签名、公证和 Gatekeeper 继续看 Developer ID 发布手册。

组件 / 版本快照 用途 / 所在层 职责边界 事实来源 / 代码入口 改动后的最小检查
Vitest
4.1.10		 JavaScript/Vue test runner；执行 frontend/src/*.test.js。 不会启动真实 Tauri WebView、Rust host 或 Python Sidecar。 package.json 的 test script；vite.config.js。 npm --prefix frontend run test
Vue Test Utils
2.4.11		 Vue component test helper；mount 组件、触发事件、检查渲染状态。 组件 wrapper 不是原生窗口；bridge 通常是 mock。 package.json；App.test.js 等聚焦测试。 npm --prefix frontend run test
jsdom
29.1.1		 Vitest 的模拟 DOM 环境；让 Node 中的组件测试拥有常用浏览器接口。 不等于 Safari/WKWebView，不提供真实尺寸、IME、Finder、dialog 或 Tauri IPC。 package.json；vite.config.js 的 environment: "jsdom"。 npm --prefix frontend run test；视觉/原生行为另做真实 smoke。
pytest
>=8
现场 9.1.1		 Python test runner；覆盖 core、bridge、protocol、迁移与本地工具。 只使用 fixtures、临时目录或 synthetic Vault；通过不等于真实作者场景接受。 pyproject.toml；tests/。 .venv/bin/python -m pytest

Chapter 06

Developer tooling：日常入口

项目工具只是把已存在的命令包得更顺手，不创造第二套 build、context 或验收规则。

组件 / 版本快照 用途 / 所在层 职责边界 事实来源 / 代码入口 改动后的最小检查
./dev
项目脚本，无独立 semver		 macOS 开发者 TUI；启动/重建应用、显示自己管理的日志、浏览本地文档。 只管理自己启动的进程组；不替代 Tauri lifecycle，不写日志文件，不把 manual 变成权威。 dev；test_dev_tui.py。 .venv/bin/python -m pytest -q tests/test_dev_tui.py
.venv/bin/python -m py_compile dev
CONTEXT.md + keikeu-routine
项目工作流，无独立 semver		 Agent routing；把下一任务所需的少量 tracked 文本与自动权威文件写入 ignored 根目录路由。 只读当前工作树，不上传；不替代仓库工具、权威、测试或验收，也不接受未跟踪文件。 build_context_pack.py；test_build_context_pack.py；keikeu-routine。 .venv/bin/python -m pytest -q tests/test_build_context_pack.py
刷新后人工审查 header 与每个文件边界

两个入口，仍是一套命令

  • a：使用现有 Sidecar
    包装 npm --prefix frontend run tauri:dev。
  • b：重建再启动
    先调用 .venv/bin/python scripts/build_sidecar.py；成功后才启动 Tauri。
  • 文档页
    扫描本地 manual/active docs，并以纯文本搜索和预览；不实现另一套渲染器或索引。

五分钟键位与失败处理见 TUI 极简使用手册。 Context route 只在最终工作树/提交状态后刷新；它不会进入 Git，也不会因 TUI 可浏览 全部手册而自动收集 docs/manual/。

Chapter 07

六类改动怎么找入口

不需要先读完整仓库。按任务选择一条窄路线，读 authority、目标、调用方和直接测试。

我要改 先读 常见入口 最小证据
UI App Shell design 与相关组件测试。 frontend/src/*.vue、style.css 聚焦 Vitest + Vite build；交互/视觉变化再做真实 viewport/Tauri 检查。
原生能力 Architecture、capability 与调用方。 frontend/src/bridge.js、commands.rs、lib.rs 前端聚焦测试 + Cargo test + 真实 Tauri smoke。
protocol Paper v4 design 与两端 direct tests。 bridge.rs ↔ protocol.py Rust bridge tests + tests/test_bridge_protocol.py；两端版本必须同步。
文件规则 SPEC、RULES 与 Paper grammar。 src/keikeu_core/，再追 service.py 聚焦 pytest；迁移/删除/恢复先在 fixtures 或副本，绝不从唯一真实 Vault 起步。
测试 测试与证据手册 和被测行为 authority。 tests/、frontend/src/*.test.js、Rust inline tests 失败前能复现，修复后聚焦通过；不要复用旧 pass count。
构建 构建与打包手册 和对应 manifest/lock。 build_sidecar.py、tauri.conf.json、三个 manifest 重建受影响产物；桌面链变化再做 Tauri smoke。

Chapter 08

版本与事实边界

版本快照帮助排错，不替代版本文件。先问“谁声明它、谁解析它、我现在实际运行谁”。

2026-08-29 快照

生态 声明契约 现场命令 已知边界
Node / npm 22.23.2 / 10.9.8 v22.23.2 / 10.9.8 .node-version 仍为 22.23.1；校准留给 Road v0.8 的工具链基础 Gate。
Python >=3.11,<3.14 3.13.15 .python-version 仍为 3.13.14；校准留给 Road v0.8 的工具链基础 Gate。
Rust / Cargo rust-version = 1.88 1.88.0 / 1.88.0 直接 crate 精确写在 Cargo manifest；完整解析结果在 Cargo lock。
Python build Hatchling backend；PyInstaller lock 6.21.0 PyInstaller 6.21.0 Hatchling 未作为 runtime venv 顶层包固定；不要虚构一个精确版本。

直接依赖与传递依赖

本页只列 manifest 直接声明或项目直接执行的工具。npm/Cargo/PyInstaller 的 lockfile 仍应提交并用于重建， 但 lockfile 中的传递依赖不进入新人图鉴；排查供应链或解析冲突时再按需读取。

Truth boundary

本页是非规范性人工手册，不创造依赖、架构、protocol、Vault、Git 或发布权限。 产品范围看 SPEC，工程和证据纪律看 RULES， 当前阶段看 PROJECT，模块生命周期看 Architecture；运行时事实最终以当前源码、测试、manifest 和 lockfile 为准。若它们与本页冲突，本页错。
