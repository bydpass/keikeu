06

不安全 Vault 搬迁与 v0.1 迁移

白名单外 Vault 先只读分类，再无跟随复制到 Home 并验证；格式分支只处理安全副本。

read-only source classification

白名单外立即停止写入；不跟随/解引 symlink，任何 symlink 或 special entry 都报错中止。

HOME GATE
copy regular entries + verify bytes

仅普通目录和 regular files 进入全新 Home 目标；manifest 与 bytes 相同前不切换 config。

RELOCATE
v2/v3 parse + rebuild index

安全副本逐 Paper 解析并验证重建 index；通过后才原子切换 config。

V2/V3 SWITCH
inspect_v01_vault() on safe copy

v0.1 不先按 v2/v3 解析；现有只读 preflight/manifest 通过后原子切换 config。

V0.1 SWITCH
explicit migration gate + full backup

只在切换后的安全副本上进入；备份根位于活动 Vault 外且仍在 Home 内。

BACKUP
convert in staging

旧 raw → 初稿副本 + Summary；notes → 首条 Highlight；title → legacy_title。

STAGE
read every staged Paper

数量、Summary、初稿副本和报告全部验证。

VERIFY
swap + rebuild index + retain report

全部成功后才替换活动 cache 并移除旧 Outline；Home 内备份仍是人工回滚来源。

DONE
搬迁的来源分类、字节复制或切换前验证失败都保持原 Vault 与 config 不变；v0.1 不先按 v2/v3 Paper 解析，取消或迁移失败只保留已选中的未改写安全副本，不写不安全来源。测试使用 fixture 或复制 Vault，禁止把唯一真实 Vault 当首测。

失败与恢复矩阵

先保护资产，再恢复便利层。

失败层检测安全响应恢复来源
Paper 输入模型验证拒绝写入并保留表单作者修正输入
外部文件改动页面打开时保存的 source bytes拒绝覆盖磁盘外部版本 + 人工决定
单 Paper 损坏index rebuild parse error隔离 error，继续其余文件Markdown 手工修复 / 备份
Index 丢失/坏结构版本检查从 cache 重建Paper Markdown
Daily state 丢失/坏JSON/本地日期检查视为今天尚未显示；不碰 Vault无需恢复
Vault 位于 Home 外 / symlink / special entrycontainment + no-follow 只读分类立即停止写入；不支持项中止搬迁未改的原 Vault + 已验证安全副本
深层目录 / 重复 code受限枚举与全局 code 扫描报告并阻止相关 mutation作者用 Finder 修复
迁移失败checkpoint / staged verification不切换迁移 staging活动 Vault + 其外但 Home 内的完整备份
Provider 冲突未知/重复文件不自动合并操作系统与作者判断
