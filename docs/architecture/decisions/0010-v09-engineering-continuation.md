# ADR-0010：中断 v08 后接续工程与原生移动方向

日期：2026-09-20。状态：开发者批准，全计划 YOLO 覆盖 [v09](../../road-v09.md) CP0–CP4。

## 背景与决定

v08 的 CP0–CP4 工程和 CP5 候选存在，15 组真实场景曾通过，但 B14 与最终接受未完成。开发者中断旧路线，选择原生移动组件，尽可能保留 Rust；Mac 重构延后，Windows 保留现有技术架构。

以 `deaece8` 为工程代码来源，集成 `78eb755` 的手册、`0447e16` 的已授权归档清理及 `670142d` 的批准计划。此接续只建立 v09 CP0，不把未通过的 v08 CP5 改记为通过。两份原工作区保留，历史保持追加式。

v09 只重排目录、独立纯规则、修复开发工具并验证现有 Mac 路径；v09.01 单独实施 SwiftUI。保存恢复运行层的解耦、B14、新客户端同步、Windows 适配和发行均保留后续门槛。ADR-0009 的全平台 Vue/Tauri 方向由本决定替换；数据安全和桌面能力对等门槛继续有效。

## 后果与复查

现有 Swift 平台适配和 Rust 文件运行层继续复用，不新增业务副本。旧包与旧验收结果不能证明新 HEAD。CP0 完成后，此未接受候选接续例外耗尽；后续 CP 均从本 Road 上一已接受／YOLO 提交开始。回退使用保留的分支或逆向提交，不删除作者资产。
