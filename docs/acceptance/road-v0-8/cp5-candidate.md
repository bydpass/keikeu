## 回退与问题记录

- 候选使用独立标识，不替换正式桌面 app；停止候选进程可返回原 app。
  不删除候选 Vault、恢复 journal 或云冲突文件，不把旧二进制指向新私有 journal。
- 云端变化按导出的原字节副本及当前磁盘状态人工核对；不自动选赢者、合并、改 code 或重发未知写入。
- 已知工程上限：原生文件批次和单份私有 journal 串行处理，大量稿件或 provider 延迟时可能影响响应时间；
  尚无性能测量，不把它改成额外后台服务。本阶段未据此新增产品范围。
- 未解决 P0／P1 或任一必需项无证据时，停在候选待验。全部必需项通过并取得开发者接受之后，才完成 CP5。
  Road 快照、tag、push 和发布另行处理。
